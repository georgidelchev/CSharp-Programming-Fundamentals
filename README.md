## 📖 About

This repository contains my complete solutions for the **C# Programming Fundamentals** course at [SoftUni](https://softuni.bg) — the natural progression from Programming Basics, bridging the gap between beginner syntax and real object-oriented programming.

The course introduces core computer science concepts through practical problem solving in C#: working with collections, designing reusable methods, modelling data with classes, processing strings and regular expressions, and applying structured thinking to increasingly complex problems.

Every solution has been submitted to the **Open Judge System (OJS)** and achieved a perfect **100/100** score.

## 📚 What This Course Covers

Fundamentals is where C# development starts to feel real. Topics go well beyond syntax:

- **Arrays & Lists** — indexing, iteration, sorting, searching, and manipulation algorithms
- **Methods** — parameters, return types, overloading, and writing clean reusable logic
- **Objects & Classes** — the first steps into OOP: fields, properties, constructors, and encapsulation
- **Associative Arrays** — `Dictionary<K,V>` and `SortedDictionary` for key-value data modelling
- **Text Processing** — `StringBuilder`, string methods, formatting, and parsing
- **Regular Expressions** — pattern matching, validation, extraction, and substitution with Regex
- **Basic HTML & CSS** — a brief introduction to web markup and styling

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/georgidelchev/CSharp-Programming-Fundamentals.git
   cd CSharp-Programming-Fundamentals
   ```

2. **Open any solution** — each folder contains `.sln` or `.cs` files openable in Visual Studio or Rider.

3. **Browse by topic** — navigate to the module folder matching the concept you want to explore.
